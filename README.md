🏛️   Çarşı — Municipal Loyalty Platform
<p> <img src="https://img.shields.io/badge/React_Native-20232A?style=flat-square&logo=react&logoColor=61DAFB" /> <img src="https://img.shields.io/badge/Expo-000020?style=flat-square&logo=expo&logoColor=white" /> <img src="https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white" /> <img src="https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white" /> <img src="https://img.shields.io/badge/REST_API-0F0F0F?style=flat-square&logo=fastapi&logoColor=D0FF71" /> </p>
🏢   Context	Melikgazi Municipality · R&D Internship — 2026
🎯   Problem	Local shops struggled to stay visible in digital channels and had no loyalty mechanism to bring customers back. Citizens had no single place to follow district campaigns.
🛠️   Solution	Built the app from zero in React Native, Expo & TypeScript. Citizens earn reward points by scanning QR codes and receipts; businesses get their own campaign management panel. Feature‑based modular architecture, state via Context API + custom hooks, data through REST APIs + PostgreSQL.
✅   Result	Delivered production‑ready, end‑to‑end within the internship period. New campaign types can be added with zero code duplication.

🔥   Wildfire Detection CNN
<p> <img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" /> <img src="https://img.shields.io/badge/TensorFlow-FF6F00?style=flat-square&logo=tensorflow&logoColor=white" /> <img src="https://img.shields.io/badge/Keras-D00000?style=flat-square&logo=keras&logoColor=white" /> <img src="https://img.shields.io/badge/Grad--CAM-0F0F0F?style=flat-square&logoColor=D0FF71" /> <a href="https://github.com/UnalPilavci/Wildfire-Detection-CNN-Project-Bootcamp"><img src="https://img.shields.io/badge/View_Repo-181717?style=flat-square&logo=github&logoColor=D0FF71" /></a> </p>
🏢   Context	Akbank Deep Learning Bootcamp — 2025
🎯   Problem	In wildfires, early detection directly determines response time. But in a safety‑critical scenario a black‑box model isn't enough — it has to justify its decision.
🛠️   Solution	Enriched the dataset with augmentation, then compared a from‑scratch CNN against transfer learning. Produced Grad‑CAM heatmaps to make the model's reasoning visible.
✅   Result	Transfer learning reached higher accuracy in less training time. Grad‑CAM confirmed the model genuinely focuses on the smoke/flame region — not background artefacts. Released open source.
