🚀 Featured Projects
🏛️ Çarşı — Municipal Loyalty Platform
React Native · Expo · TypeScript · PostgreSQL · REST API

A municipal app connecting local businesses with citizens. Citizens earn reward points by scanning QR codes and receipts; businesses get a campaign management panel. Built from scratch during my R&D internship at Melikgazi Municipality and delivered production‑ready end‑to‑end within the internship period. Feature‑based modular architecture means new campaign types can be added with zero code duplication.

🔥 Wildfire Detection CNN
Python · TensorFlow/Keras · Transfer Learning · Grad‑CAM

Deep learning system detecting wildfires from satellite/camera imagery. In a safety‑critical scenario a black‑box model isn't enough — so I used Grad‑CAM heatmaps to prove the model actually focuses on the smoke/flame region. Transfer learning beat the from‑scratch CNN in both accuracy and training time.

🥗 NutriLens AI
React Native · TypeScript · AI API

AI‑powered nutrition assistant built at the Artificial Intelligence & Technology Academy bootcamp. Most calorie trackers get abandoned in week one because manual entry is exhausting — so we designed around minimising user input, letting AI do the analysis.

🛰️ Autonomous Reconnaissance Vehicle
Python · Embedded Systems · Sensor Fusion · Robotics — TÜBİTAK 2209‑A

Project lead of a research project funded by the TÜBİTAK University Students Research Projects Programme. Designed a control flow that processes sensor data for obstacle detection and autonomous route decisions, removing operator dependency in risky terrain. Also ran the literature review, budgeting and TÜBİTAK reporting.
